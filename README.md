# Marteen Hotel

MVP ระบบจองห้องพักด้วย PHP และ MySQL รองรับการสมัครสมาชิก เข้าสู่ระบบ ค้นหาห้องว่างตามวันที่ ส่งคำขอจอง ดูประวัติ และยกเลิกการจองที่ยังไม่เริ่มเข้าพัก

## ความต้องการ

- PHP 8.1 ขึ้นไป พร้อมส่วนขยาย PDO, PDO MySQL และ mbstring
- MySQL 8.0 ขึ้นไป หรือ MariaDB รุ่นที่รองรับ InnoDB และ prepared statements
- XAMPP สำหรับพัฒนาบนเครื่อง

## เริ่มต้นใช้งานด้วย XAMPP

1. วางโฟลเดอร์โปรเจกต์ไว้ใน `C:\xampp\htdocs\marteen-hotel`
2. เปิด Apache และ MySQL จาก XAMPP Control Panel
3. เปิด phpMyAdmin แล้วนำเข้าไฟล์ `database/schema.sql` หรือรัน SQL นี้ใน MySQL
4. ตรวจค่าเชื่อมต่อฐานข้อมูลใน `config/config.php` ค่าเริ่มต้นสำหรับ XAMPP คือ `127.0.0.1`, ฐานข้อมูล `marteen_hotel`, ผู้ใช้ `root` และรหัสผ่านว่าง
5. เปิด `http://localhost/marteen-hotel/`

ค่าฐานข้อมูลสามารถกำหนดผ่าน environment variables `DB_HOST`, `DB_NAME`, `DB_USER` และ `DB_PASS` ได้

## ขอบเขตใน MVP

- สมัครสมาชิกพร้อมตรวจข้อมูลและเข้ารหัสรหัสผ่านด้วย `password_hash()`
- เข้าสู่ระบบและออกจากระบบผ่าน session
- ค้นหาห้องพักที่รองรับจำนวนผู้เข้าพักและยังว่างตามช่วงวันที่
- คำนวณยอดจากราคาต่อคืน จำนวนคืน และจำนวนห้อง ก่อนสร้างคำขอจอง
- ป้องกันการจองเกินจำนวนห้องด้วย transaction และล็อกแถวประเภทห้องระหว่างตรวจสอบ
- ดูและยกเลิกรายการจองที่ยังไม่เริ่มเข้าพัก
- ใช้ prepared statements, output escaping และ CSRF token ในแบบฟอร์มที่เปลี่ยนข้อมูล

การจอง `pending`, `confirmed` และ `checked_in` จะกันจำนวนห้องในช่วงวันที่ทับซ้อนกัน โดยคืนที่เช็กเอาต์สามารถถูกจองต่อได้ ระบบนี้คิดจำนวนห้องจากประเภทห้อง ยังไม่จัดสรรหมายเลขห้องจริง และยังไม่มีหน้าผู้ดูแลระบบ ระบบชำระเงิน หรืออัปโหลดหลักฐาน

ก่อนเปิดใช้งานจริง ให้ตั้งค่าบัญชีฐานข้อมูลที่ปลอดภัย เปิด HTTPS และสร้างบัญชีผู้ดูแลผ่านการจัดการฐานข้อมูลโดยตรง ไม่ควรใช้บัญชีฐานข้อมูล root บน production
